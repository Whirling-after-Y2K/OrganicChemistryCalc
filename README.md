# 有机化学计算器（OrganicChemistryCalc）

面向高中化学范围的有机化学计算工具：用 Python 建立分子结构模型，支持官能团分析、
同分异构体枚举、有机反应模拟、反应结果联动检索与合成路线规划，并带一个本地 Web
图形界面。分子图、同构判等、子结构匹配与 2D 布局全部自研，不依赖 RDKit 等第三方
化学库；界面为 Flask 服务端 + Vue 运行时 + canvas，没有前端构建步骤。

## 快速使用

需要 Python 3.10+。

```powershell
python -m pip install -r requirements.txt # 仅图形界面需要 Flask
python oc_web.py # 启动并打开浏览器
python oc_web.py molecule_library\苯酚.mol # 启动后自动加载该分子
```

端口默认为1891。<br>

**_当前通过文件管理器打开/导入分子文件时可能会出现神秘的卡顿问题,可以通过将分子文件拖拽至页面内打开的方式来规避这一问题_**

## 目前的局限

- 元素表限于 `C/N/O/H/F/Cl/Br/I`。
- 不考虑立体化学，形式电荷等。
- π 体系目前只覆盖苯环与硝基。
- 反应引擎共 23 条规则，分 7 类。下表未列出的反应类型、试剂组合与位点选择
  一律不支持；同一试剂的其他写法（如用 `HI` 代替 `HBr`）也不做等价展开。

| 类别 | 反应           | 条件             | 试剂        |
| ---- | -------------- | ---------------- | ----------- |
| 加成 | 烯烃加氢       | 催化剂/加热      | `H2`        |
| 加成 | 烯烃与卤素加成 | 不限定           | `Cl2`/`Br2` |
| 加成 | 烯烃与HX加成   | 不限定           | `HCl`/`HBr` |
| 加成 | 烯烃水化       | 催化剂/加热      | `H2O`       |
| 加成 | 炔烃部分加氢   | 催化剂/加热      | `H2`        |
| 加成 | 炔烃完全加氢   | 催化剂/加热      | `H2`×2      |
| 加成 | 苯加氢         | Ni/加热          | `H2`×3      |
| 取代 | 烷烃卤代       | 光照             | `Cl2`/`Br2` |
| 取代 | 苯卤代         | FeX3/加热        | `Cl2`/`Br2` |
| 取代 | 苯硝化         | 浓硫酸/加热      | `HNO3`      |
| 取代 | 醇卤代         | 加热             | `HCl`/`HBr` |

| 取代 | 苯酚与溴水     | 溴水             | `Br2`×3     |
| 消去 | 卤代烃消去     | NaOH醇溶液/加热  | 无需试剂    |
| 消去 | 醇分子内脱水   | 浓硫酸/170℃/加热 | 无需试剂    |
| 氧化 | 醇催化氧化     | Cu或Ag/加热      | `O2`        |
| 氧化 | 醛催化氧化     | 催化剂/加热      | `O2`        |

| 酯化 | 苯酚酯化       | 浓硫酸/加热      | 羧酸        |
